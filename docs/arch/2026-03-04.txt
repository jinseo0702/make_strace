음수가 들어가야 하는 자리에 음수가 해석이 되는게 안니라 비트 그자체가 해석이 되고 있는게 문제가 된다.
그 이유는 다음과 같다.

```c
int fmt_int(unsigned long long v, char *out, size_t n, int *offset){
	long long temp = (long long)v;
	*offset += sprintf(out + *offset, "%lld", temp);
	return n;
}
```

여기서 unsigned long long 을 다시 long long 으로 캐스팅 해주는 과정에서 음수의 비트가 해석이 되는 문제가 의도하지 않은 방향으로 발생하고 있다.

방금 생각한 수정해야하는 방향은 다음과 같다.
 - 인자 type을 더욱 구체화 한다.

이유는 다음과 같다.
현재 발생하는 문제는 type 의 불일치이다. negative 값을 양수로 해석하거나 unsigned 값을 negative로 해석한다.
그렇다면 더욱 해석을 세분화 하면 된다.

unsigned 에 관련된 type
long에 관련된 type 을 추가해보자
